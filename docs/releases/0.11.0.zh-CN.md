# Bloodborne Save Editor Gems 0.11.0

[English](https://github.com/Trit0N10/bloodborne-save-editor-gems/releases/tag/v0.11.0) | **简体中文**

用于编辑已解密《血源诅咒》角色存档的桌面工具，基于 Noxde/Bloodborne-save-editor 0.10.0，采用 GPL-3.0。本版本提供默认英语、可切换简体中文的界面，自制图形，以及扩展后的血宝石管理功能。

- 检索 117 个血宝石预设，共有 132 个预设与形状组合。
- 添加或删除背包、仓库中的宝石，支持添加数量设置和容量检查。
- 切换语言无需重新打开存档，程序会记住语言选择。
- 提供 Windows x64 便携包、对应源码包和 SHA-256 校验文件。

## 下载与使用

在 [v0.11.0 发布页](https://github.com/Trit0N10/bloodborne-save-editor-gems/releases/tag/v0.11.0)下载 Windows ZIP，完整解压后保持 `resources` 与 `Bloodborne Save Editor Gems.exe` 同级。程序需要 Microsoft Edge WebView2 Runtime。

先退出游戏并单独备份，再打开已解密的角色文件，例如 `userdata0000`。点击「保存存档」后才会写入修改。程序未签名，自动更新已禁用；新版本从本仓库发布页下载。

## 测试

本地化、素材检查、部分基于合成数据的宝石分配与删除测试，以及前端和 Windows 程序构建均已通过。界面检查使用合成数据。本版本尚未完成真实存档和游戏内测试，请先在备份副本上验证兼容性。详情见[测试说明](../testing.md)。

存档解析与基础编辑功能来自上游，原作者署名保留在 [NOTICE](../../NOTICE.md) 中。图形素材为自制几何图形，不附带游戏原画和物品背景故事描述。
